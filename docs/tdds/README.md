# Technical Design Documents (TDDs)

Implementation notes captured at the end of each subphase, per the v3
build plan in [`../design/Avak Design V3.md`](../design/Avak%20Design%20V3.md).

Each TDD is a thin record of *what was built, what was deferred, what
surprised us*. Not a re-statement of the design — just the deltas you
need to come back to in three weeks and remember why something is the
way it is.
